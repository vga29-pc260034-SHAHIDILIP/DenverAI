\# 🤖 Denver AI - Java Desktop Assistant



Denver AI is a Java-based desktop assistant with GUI, built using Swing and integrated with Ollama AI for intelligent responses.



\---



\## 🚀 Features



\- 💬 AI Chat Interface (Swing GUI)

\- 🧠 Memory System (remembers name \& preferences)

\- 📋 Todo Manager (add, complete, remove tasks)

\- 🌐 Command system (open websites like YouTube, Google)

\- 🤖 Ollama AI Integration (local LLaMA model support)



\---



\## 🛠️ Technologies Used



\- Java

\- Swing GUI

\- File Handling (Memory System)

\- Ollama AI (LLM integration)



\---



\## ▶️ How to Run



1\. Install Java (JDK 8+)

2\. Install Ollama and run model

3\. Compile project:



```bash

javac \*.java
```



4\. Run program:



```bash

java Main

```
